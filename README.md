# Web-Watch

A small set of command-line tools to monitor web pages and the Dresden tango calendar and notify you by email.

Disclaimer: This is a little test for doing something with langchain4j and OpenAI, though it is useful for me.
I run that from cron in my virtual server. Please note that most of that, including the documentation,
was AI generated by GitHub Copilot Agent with GPT-5-mini, since I like to play around with that to learn
how to best do that and its rapidly raising limits.


This repository contains a few focused Java command-line utilities (packaged as a fat JAR) and a couple of helper scripts under `bin/` that make automation and notification simple.

Quick summary
- `--checkpages` (See `doc/checkpages.md`): extract parts of web pages (configured by CSS selectors), persist lightweight captures under `data/checkpages/`, and report changes.
- `--tango` (See `doc/checktango.md`): extract concerts from the Dresden tango calendar via an LLM-assisted extractor and report newly announced concerts.

Requirements
- Java 17 (project is configured for Java 17 in `pom.xml`).
- Maven (for building the fat JAR via the supplied `pom.xml`).
- A command-line SMTP client for the notification script (the provided scripts expect the `sendemail` utility; you may adapt them to another mail client).
- If you use the tango feature, set `OPENAI_API_KEY` in the environment (see `doc/checktango.md` for details).

Build
From the project root:

```bash
mvn package
```

The Maven build produces a fat JAR at `target/webwatch-1.0-SNAPSHOT-jar-with-dependencies.jar` (the `maven-assembly-plugin` configured in `pom.xml` creates this artifact).

Run (examples)
- Run the checkpages tool directly:

```bash
java -jar target/webwatch-1.0-SNAPSHOT-jar-with-dependencies.jar --checkpages
```

- Run the tango extractor directly:

```bash
java -jar target/webwatch-1.0-SNAPSHOT-jar-with-dependencies.jar --tango
```

Helper scripts (short)
- `bin/checkforchanges.sh`
  - Runs the fat JAR with `--checkpages`. If the Java process exits with code `0` (indicating at least one page changed), the script pipes the captured output to `bin/sendmailtome.sh` with subject `webwatch: pages changed`.
- `bin/checktango.sh`
  - Runs the fat JAR with `--tango`. If new concerts are found (Java exits `0`), the script pipes the output to `bin/sendmailtome.sh` with subject `new tango concerts` and moves `data/tango-concerts-seen-new.json` to `data/tango-concerts-seen.json`.
- `bin/sendmailtome.sh`
  - Small helper that reads SMTP configuration from `$HOME/.secrets/.sendmailtome` and calls the `sendemail` CLI to deliver mail. See `doc/sendmailtome.md` for configuration details.
- `bin/hpsxsynctoionos.sh`
  - Convenience helper that runs `mvn install` and rsyncs the project and artifacts to a remote host (`hps@hpsionos`). Use only if you control that host and have SSH access configured.

Configuration notes
- `bin/sendmailtome.sh` expects a file at `$HOME/.secrets/.sendmailtome` with shell-style `KEY=value` lines. Required keys: `FROM`, `TO`, `SMTP`, `USER`, `PASS`. Optional: `TLS` (defaults to `yes`). See `doc/sendmailtome.md` for examples and security advice.
- The tango feature uses an OpenAI-compatible client via langchain4j. Provide `OPENAI_API_KEY` in the environment when running `--tango`. The code expects a model and client configured via langchain4j; see `doc/checktango.md` for details and privacy notes.

Data and state
- Configuration: `data/checkpages-config.json`
- Persistent captures: `data/checkpages/` (per-page JSON captures)
- Tango state files: `data/tango-concerts-seen.json` and `data/tango-concerts-seen-new.json`

Security and privacy
- Keep API keys and SMTP credentials out of the repository. The scripts recommend `chmod 600` on the sendmail config file.
- The tango extractor sends cleaned HTML to an LLM provider; be mindful of any privacy implications.

Troubleshooting
- If `bin/checktango.sh` or `bin/checkforchanges.sh` reports "Jar not found" then run `mvn package` and confirm the fat JAR exists at `target/webwatch-1.0-SNAPSHOT-jar-with-dependencies.jar`.
- If `sendmailtome.sh` reports `sendemail command not found`, install the `sendemail` utility or adapt the script to another mail client (e.g., `msmtp`, `swaks`, `mailx`, or a small Python helper).
